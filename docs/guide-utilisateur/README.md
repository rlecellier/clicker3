# Guide du joueur de Sainte-Croissance

Bienvenue. Vous allez vivre une vie entière, de 18 ans à la fin de votre exercice,
dans une ville qui croît sans demander l'avis de personne. Ce guide explique ce
que fait chaque bouton, d'où viennent les chiffres et ce que la version 1.5 du
jeu change. Il décrit le jeu tel qu'il est, pas tel qu'il était prévu.

Les montants du guide ont été relevés dans le jeu lui-même. Si vous constatez un
écart, c'est le jeu qui a raison : signalez-le.

## Par où commencer

- Vous découvrez le jeu : lisez [La version 1.5](la-version-1-5.md), puis
  [Débuter](debuter.md).
- Vous cherchez le rôle d'un onglet : voyez la liste ci-dessous.
- Vous cherchez ce que fait un achat : voyez [Les améliorations](ameliorations.md)
  ou [Les entreprises](entreprises.md).
- Un mot vous échappe : voyez le [Glossaire et questions fréquentes](glossaire-et-faq.md).

## Une règle pour tout le guide

Tous les prix sont en euros. Une « période » est un mois du jeu. Les montants
par période sont donc des montants par mois. Une vie compte 684 mois.
