# Onglet Finance

[Sommaire](README.md) · Raccourci : touche 8 · Précédent : [Comptes](onglet-comptes.md) · Suite : [Ville](onglet-ville.md)

Dans la vie, personne ne garde des millions sur son compte courant. Votre argent
se répartit **tout seul** entre le **compte courant** (là où tombent revenus et
dépenses, il ne rapporte rien) et des **placements** qui rapportent chaque mois.
L'argent affiché en haut de l'écran est le **total de tous les comptes**.

L'en-tête de la page donne le total, le compte courant (avec son matelas), le
**capital placé** et le **rendement attendu** le mois suivant.

## Les placements

| Placement                                     | Débloqué par                               | Rendement par mois | Plafond du capital placé |
| --------------------------------------------- | ------------------------------------------ | ------------------ | ------------------------ |
| Livret A                                      | Palier 1 (« Partenaire de confiance »)     | 0,1 %              | 22 950 €                 |
| Livret de développement durable et solidaire  | Palier 1 (« Partenaire de confiance »)     | 0,1 %              | 12 000 €                 |
| Plan d’épargne logement                       | Palier 2 (« Acteur majeur »)               | 0,25 %             | 61 200 €                 |
| Compte-titres                                 | Palier 3 (« Vous êtes devenu une marque ») | 0,6 %, variable    | aucun                    |

La réputation ne fait que **débloquer** un compte. Une fois débloqué, vous le
remplissez jusqu'à son plafond, qui est fixe. Le compte-titres, lui, n'a pas de
plafond et rapporte plus que tous les autres : ses intérêts se capitalisent, et
le capital peut grimper de façon exponentielle.

## La répartition automatique

- Le compte courant garde un **matelas** : deux mois de dépenses fixes (loyer,
  train de vie, charges, salaires). Il ne bouge pas.
- Tout ce qui dépasse le matelas va dans le **premier compte qui a de la place** :
  Livret A, LDDS, PEL, puis compte-titres. Quand un plafond est atteint, le
  surplus passe au compte suivant ; le compte-titres, sans plafond, absorbe tout
  le reste.
- Un revenu remplit d'abord le compte courant, puis les placements.
- Une dépense (achat, études, loyer…) puise d'abord dans le compte courant,
  puis dans le compte qui rapporte le moins. Rien n'est jamais bloqué : vous
  n'êtes à découvert que si le total de tous les comptes ne suffit pas.

## Le rendement

- À chaque clôture de mois, un placement qui rapporte verse son rendement sur
  le **compte courant** (ligne « Rendement des placements » des
  [Comptes](lire-les-comptes.md), avec le tableau de bord) ; s'il dépasse le
  matelas, il est placé à son tour.
- Il s'applique aussi pendant votre absence : c'est le principe d'un placement.
- Le compte-titres bouge avec l'actualité. La **bulle internet** ajoute 1,2
  point de rendement par mois jusqu'à son éclatement ; le **krach** de 2001 puis
  la **crise financière** retirent 3 points par mois pendant un an : le
  rendement devient négatif et le capital placé fond d'autant (la perte est
  comptée dans les autres dépenses). Les comptes d'épargne ne bougent pas.
- Le ton reste celui du jeu : « épargne optimisée », « valeur actionnariale ».
