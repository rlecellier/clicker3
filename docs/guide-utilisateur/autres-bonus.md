# Les autres sources de bonus

[Sommaire](README.md) · Précédent : [Les améliorations](ameliorations.md) · Suite : [Les entreprises](entreprises.md)

Les [améliorations](ameliorations.md) ne sont pas la seule manière de progresser.
Quatre autres sources comptent : les compétences, la réputation, les quartiers
et les événements.

## Les quatre compétences

Une compétence ne multiplie rien. Chaque **palier** atteint ouvre une porte : un
poste, une entreprise, une amélioration. Le tableau dit ce que chaque palier
débloque (les paliers sont à 2, 9, 41 et 81 points).

| Compétence   | Déblocages par palier                                                                                                      |
| ------------ | -------------------------------------------------------------------------------------------------------------------------- |
| Métier       | 1 : emploi « Employé polyvalent », BTS ; 3 : emploi « Chargé de mission » (avec la réputation 1) ; 6 : emploi « Directeur adjoint de la transformation » (avec la réputation 2 et le Directeur de la transformation) ; 8 : procédure de travail, fin du cursus |
| Gestion      | 1 : Licence ; 2 : Atelier d'assemblage, Boutique ; 3 : Étagères en kit, Premier collaborateur ; 4 : Manufacture, Tableau de bord ; 5 : Hypermarché (avec le Parc Horizon), Équipe de collaborateurs ; 6 : Site de production délocalisé, Entrepôt logistique ; 7 : Plateforme en ligne (à partir de janvier 2000, avec le Pôle d'Excellence) ; 8 : Directeur de la transformation (avec la réputation 2), procédure de travail |
| Intelligence | 1 : Coaching, Agenda électronique ; 3 : cure de ginkgo ; 4 : Assistante de direction ; 5 : séminaire intensif ; 8 : procédure de travail, fin du cursus |
| Endurance    | 1 : Studio rénové ; 3 : Pavillon aux Tilleuls ; 5 : Loft au Pôle d'Excellence, clinique du sommeil ; 7 : procédure de travail ; 8 : fin du cursus |

Une case vide veut dire que ce palier n'ouvre rien de précis. Le palier 8 ne sert qu'à
terminer un cursus : le jeu cesse alors de le proposer dans Étudier.

Gestion est la compétence qui ouvre le plus : c'est elle qui fait grandir
l'entreprise. Elle ne progresse que par l'étude de la Gestion des opportunités
(le travail à un poste ne donne que du Métier).

## La réputation

La réputation est à la fois un **palier** (qui ouvre) et une **monnaie** (qu'on
dépense). Elle s'ouvre sur trois paliers : Partenaire de confiance (6 gagnés),
Acteur majeur (100 gagnés), « Vous êtes devenu une marque » (170 gagnés).

| Palier de réputation | Ce qu'il ouvre                                                                                         |
| -------------------- | ------------------------------------------------------------------------------------------------------ |
| 1, Partenaire de confiance | Emploi « Chargé de mission », Équipe de collaborateurs, quartier Les Hauts-Fourneaux             |
| 2, Acteur majeur     | Emploi « Directeur adjoint de la transformation », Directeur de la transformation, Plan de communication, quartier Parc d'activités Horizon |
| 3, Vous êtes devenu une marque | Quartier Le Pôle d'Excellence                                                          |

Ce qu'elle demande à dépenser :

| Dépense                                   | Réputation |
| ----------------------------------------- | ---------- |
| Emploi « Chargé de mission »              | 10         |
| Emploi « Directeur adjoint de la transformation » | 9  |
| Quartier Les Hauts-Fourneaux              | 1          |
| Quartier Parc d'activités Horizon         | 22         |
| Quartier Le Pôle d'Excellence             | 33         |

Les sources de gain et de perte sont dans [Les systèmes](systemes.md#la-réputation).
Deux améliorations modifient la façon d'en gagner : les Cartes de visite (+25 %
par action de travail) et le Plan de communication (+50 % par article vendu).

## Les quartiers

Un quartier ouvert **fait plus que figurer sur la carte**.

- Les Hauts-Fourneaux accueillent la Manufacture ; le Parc d'activités Horizon
  accueille l'Hypermarché et le Site de production délocalisé ; le Pôle
  d'Excellence accueille la Plateforme en ligne. Sans quartier, ces
  bâtiments se posent aux Tilleuls.
- Deux entreprises **exigent** leur quartier pour être achetées : l'Hypermarché
  (Parc d'activités Horizon) et la Plateforme en ligne (Pôle d'Excellence).
- Chaque quartier ouvert apporte ses jauges d'impact ([Ville](onglet-ville.md)).

Détail dans [Les systèmes](systemes.md#les-quartiers).

## Les événements

Les événements historiques portent de petits effets, bons ou mauvais,
qui arrivent à des dates fixes. Un seul est un bonus : la **bulle internet**
(+20 % sur le prix de vente de tous les articles, de mars 2000 à septembre 2001).
Les autres sont des charges, listées dans [Les événements](evenements.md).
